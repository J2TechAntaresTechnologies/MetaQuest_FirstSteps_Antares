## Resumen
Este repositorio contiene el tutorial “WebXR First Steps”, un recorrido práctico para crear una experiencia WebXR (VR) usando Three.js. El proyecto es 100% frontend: se sirve con Webpack Dev Server seguro (HTTPS en el puerto 8081), incluye emulación integrada mediante IWER/@iwer/devui, y no requiere backend para funcionar.

Objetivos: aprender los fundamentos de una app WebXR (escena, cámara, render loop XR), entrada con controladores, animación basada en tiempo, carga de modelos GLTF, detección de impactos, audio posicional y hápticos, y empaquetado para despliegue estático. Keywords: WebXR, Three.js, VR, controllers, GLTF, haptics, IWER, emulación, Webpack, tutorial.
